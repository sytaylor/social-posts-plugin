# Visual Strategy & Image Sourcing Guide

**Purpose:** System for finding, creating, and optimizing visuals that amplify Simon's posts and boost LinkedIn performance.

**Principle:** Every post needs a visual. Match the visual format to the hook type and story structure.

**Performance Data:**
- Multi-image posts: 1.0x engagement (LinkedIn algorithm boost)
- Video (1-3 min): 1.8x engagement
- Single image: Baseline
- Text-only: 0.6x engagement (algorithm penalty)

## Section 1: Person-Focused Visuals

### Format 1A: Quote Over Face (McKinsey Style)

**When to use:**
- "This is [Name]" posts
- Profiling founder/executive
- Highlighting specific insight

**Structure:**
```
[Professional headshot - 60% of image]
[Quote overlay - large, readable font]
[Attribution: Name, Title, Company - bottom]
```

**How to source the image:**

**Step 1: Find Professional Headshot**
```
Google Image Search:
"[Person Name] headshot"
"[Person Name] linkedin"
"[Person Name] [Company] photo"

LinkedIn:
Visit their profile → Download profile photo
Note: Use high-res version if available

Company Press Kit:
Check "[Company].com/press" or "/about"
Often has high-res executive photos

Crunchbase Profile:
Often has better quality than LinkedIn
```

**Step 2: Verify Image Rights**
- ✅ LinkedIn profile photos: Fair use for commentary
- ✅ Company press kit: Explicitly for media use
- ✅ Official company announcements: Context-appropriate
- ⚠️ Paywalled news sites: Use company source instead
- ❌ Getty/stock photos with watermark: Need license

**Step 3: Design Specs**
```
Dimensions: 1200x1200px (square) or 1200x628px (landscape)
Resolution: 72 DPI minimum (web)
Format: PNG (for transparency) or JPG

Quote text:
- Font: Sans-serif (Helvetica, Arial, Inter)
- Size: 48-72pt (readable on mobile)
- Color: White text on dark overlay OR dark text on light
- Max length: 2-3 lines (must be readable at thumbnail size)

Attribution:
- Font size: 24-36pt
- Include: Name • Title • Company
- Bottom right or bottom center
```

**Tools:**
- **Canva** - Templates available, easy quote overlay
- **Figma** - More control, professional design
- **Adobe Express** - Quick, mobile-friendly

**Example:**
```
Image: Sam Altman headshot
Overlay: "The AI most nobody can replicate"
Attribution: Sam Altman • CEO • OpenAI

OR

Image: MrBeast
Overlay: "$200M investment in creator IP"
Attribution: MrBeast • Creator • 300M+ subscribers
```

## Section 2: "Finally" Moment Visuals

### Format 2A: Before/After Comparison

**When to use:**
- "AI is finally getting personal" moments
- Product evolution stories
- Industry maturation posts

**Structure:**
```
Left column: "Before" or "Standard"
Right column: "After" or "New"
Center: Clear dividing line or vs.
```

**Sourcing strategy:**

**For product screenshots:**
1. **Take your own screenshots**
   - Visit product websites
   - Sign up for demos if needed
   - Capture clean, high-res screens
   - Crop to focus on key difference

2. **Use official product images**
   - Company blog posts
   - Press releases
   - Product pages (/product, /features)

3. **Video stills**
   - YouTube product demos
   - Official company videos
   - Pause at clearest frame, screenshot

**Example (Linas's Google Personal Intelligence):**
```
Left: "Standard Chat" screenshot
Right: "Personal Intelligence" screenshot
Label: Clear headers
Duration: 13-second video walkthrough
```

**Design specs:**
```
Dimensions: 1200x628px (LinkedIn video thumbnail)
Video: 10-30 seconds max
Format: MP4, H.264 codec
Headers: Bold, contrasting color
Side-by-side or sequential reveal
```

---

### Format 2B: Timeline Showing Evolution

**When to use:**
- Multiple "failed attempts" before success
- Industry maturation narrative
- Pattern validation

**Structure:**
```
2020 → [Failed approach 1]
2022 → [Failed approach 2]
2024 → [Failed approach 3]
2026 → [Finally: Success]
```

**Example:**
```

2022 → Creator DAOs 🏛️

Timeline showing evolution
Each with icon/visual representation
Final one highlighted (the "finally")
```

## Section 3: Dollar Amount Visuals

### Format 3A: Number + Logo

**When to use:**
- Investment announcements
- Fundraising news
- Acquisition amounts

**Structure:**
```
Top: Company logo(s)
Center: Large dollar amount ($200M)
Bottom: Context (what it's for)
```

**Sourcing company logos:**

**Official sources (preferred):**
```
1. Company website footer
   → Look for SVG or PNG logo file
   → Download from /press or /brand

2. Press kit
   → [company].com/press
   → Usually includes multiple formats
   → SVG preferred (scalable)

3. Crunchbase
   → High-res company logos
   → Free to access

4. Clearbit Logo API
   → https://logo.clearbit.com/[domain].com
   → Example: https://logo.clearbit.com/stripe.com
   → Auto-fetches high-res logo
```

**Design specs:**
```
Dimensions: 1200x628px
Logo: Center top, max 200px height
Dollar amount: 120-180pt font, bold
Context: 36-48pt, below amount

Color scheme:
- Use company brand colors
- Or neutral (black/white/gray)
- Ensure high contrast for readability
```

**Example:**
```
[BitMine logo]  +  [MrBeast logo]

$200M

Investment in Creator IP
```

## Section 4: Convergence Visuals

### Format 4A: Venn Diagram

**When to use:**
- Two worlds colliding (crypto + creators)
- Intersection of industries
- "This is about X meeting Y"

**Structure:**
```
Circle 1: Industry A (with icon/logo)
Circle 2: Industry B (with icon/logo)
Overlap: The convergence (highlight)
```

**Example:**
```
Left circle: Crypto (🪙 Bitcoin icon)
Right circle: Creator Economy (🎥 Play button)
Overlap: "Equity Investment" (highlighted)
```

**Design approach:**
```
Use semi-transparent circles
Overlap in contrasting color
Icons represent each industry
Center text explains convergence
```

---

### Format 4B: Side-by-Side Logos

**When to use:**
- Partnerships
- Acquisitions
- Unexpected collaborations

**Structure:**
```
[Logo A] → [Logo B]
[Logo A] + [Logo B]
[Logo A] × [Logo B]
```

**Design specs:**
```
Equal size logos (or proportional to hierarchy)
Arrow/plus/multiply symbol between
Context text below
Clean, minimal design
```

## Section 5: Process/Strategy Visuals

### Format 5A: Simple Flow Diagram

**When to use:**
- "How this works" explanations
- Strategic moves with steps
- Infrastructure changes

**Structure:**
```
Step 1 → Step 2 → Step 3
[Icon] → [Icon] → [Icon]
```

**Example:**
```
AI Agent → Payment API → Real Commerce

Stripe enabling AI agents to make purchases
```

**Design approach:**
```
Icons from:
- Font Awesome (free)
- Noun Project (attribution or $)
- Flaticon (attribution or $)
- Or Canva built-in elements

Keep simple: 3-5 steps max
Use arrows or lines to show flow
Color-code by stage
```

---

### Format 5B: Strategic Positioning Map

**When to use:**
- Market positioning stories
- Competitive dynamics
- "Gambit to reshape" narratives

**Structure:**
```
2×2 matrix or positioning map
Axes: [X attribute] × [Y attribute]
Logos/names placed on map
```

**Example:**
```
Y-axis: Infrastructure (low → high)
X-axis: Consumer (low → high)

Plot: Where this company sits
Highlight: The strategic move
```

## Section 6: Multi-Example Visuals

### Format 6A: Comparison Grid

**When to use:**
- "I analyzed 100 posts" hooks
- 3+ examples of a trend
- "They all do these 3 things"

**Structure:**
```
3×3 grid or 2×2 grid
Each cell: Screenshot or logo
Consistent formatting
```

**Example:**
```
Banks Building for AI Agents:

[Stripe logo]   [Square logo]   [Chase logo]
Agent Payments  AI APIs         Agent Banking
June 2025       Aug 2025        Jan 2026
```

**Design specs:**
```
Grid: Equal-sized cells
Background: Consistent color
Text: Same font, size per cell
Spacing: Even gutters
Overall: 1200x1200px square
```

---

### Format 6B: Numbered List with Icons

**When to use:**
- "5 tactics" posts
- "3 things they all do"
- Listicle format

**Structure:**
```
1. [Icon] First thing
2. [Icon] Second thing
3. [Icon] Third thing
```

**Design approach:**
```
Numbers: Large, bold (72-96pt)
Icons: Consistent style (all line or all filled)
Text: 24-36pt, 2-3 lines max per item
Background: Gradient or solid color
```

## Image Sourcing Workflow

### Step-by-Step Process

**Step 1: Determine Format**
→ Use Decision Tree at top of this doc
→ Match hook pattern to visual format

**Step 2: Source Base Images**

**For people:**
```
1. Google: "[Name] headshot" or "[Name] linkedin"
2. LinkedIn profile (download profile photo)
3. Company press kit: [company].com/press
4. Crunchbase profile photo
5. Recent conference/event photos (Google Images, filter: last year)
```

**For company logos:**
```
1. Clearbit Logo API: https://logo.clearbit.com/[domain].com
2. Company press kit: [company].com/press or /brand
3. Crunchbase company page
4. Wikipedia (often has SVG logos)
5. Company website footer
```

**For product screenshots:**
```
1. Take your own (visit product, screenshot)
2. Official product pages ([company].com/product)
3. Company blog posts (usually embed screens)
4. YouTube demos (pause + screenshot)
5. Press releases (often include visuals)
```

**For data/charts:**
```
1. Create from scratch (Datawrapper, Flourish)
2. Company investor decks (if public)
3. Research reports (CB Insights, Gartner)
4. Recreate from text data (don't steal charts, recreate)
```

**Step 3: Verify Rights/Attribution**

**Safe to use (with attribution):**
- ✅ Company press kits (explicitly for media)
- ✅ LinkedIn profile photos (fair use for commentary)
- ✅ Self-created screenshots (transformative use)
- ✅ Logos (nominative fair use when discussing company)
- ✅ Public domain images
- ✅ Creative Commons (check license terms)

**Require permission:**
- ⚠️ Professional photography (contact photographer)
- ⚠️ Stock photos with watermarks (purchase license)
- ⚠️ Other creators' graphics (ask or recreate)

**Never use:**
- ❌ Copyrighted images without license
- ❌ Watermarked stock photos
- ❌ Other people's original artwork

**Step 4: Create/Edit Visual**

**Tools by skill level:**

**Beginner (no design experience):**
- Canva - Templates, drag-and-drop
- Adobe Express - Quick, mobile-friendly
- Kapwing - For video editing

**Intermediate (some design skills):**
- Figma - Professional, collaborative
- Keynote/PowerPoint - Surprisingly powerful
- Canva Pro - More advanced features

**Advanced (designer-level):**
- Adobe Photoshop - Full image editing
- Adobe Illustrator - Vector graphics
- Final Cut/Premiere - Professional video

**Step 5: Optimize for LinkedIn**

**Image specs:**
```
Dimensions: 1200x628px (landscape, link preview)
            1200x1200px (square, direct upload)
            1080x1080px (square, also works)

Format: JPG (smaller file) or PNG (transparency)
Size: <5MB
Resolution: 72 DPI minimum

Text overlay: Must be readable on mobile
Test: View at 25% size - can you still read it?
```

**Video specs:**
```
Dimensions: 1920x1080px (landscape) or 1080x1080px (square)
Duration: 10-30 seconds ideal (max 10 min)
Format: MP4, H.264 codec
Size: <200MB
Subtitles: ALWAYS add (70% watch muted)
Hook: First 2 seconds must grab attention
```

## Quality Checklist

Before publishing, verify:

✅ **Mobile Readable**
- [ ] Text is legible at thumbnail size
- [ ] Key elements visible on small screen
- [ ] Contrast is high enough

✅ **On-Brand**
- [ ] Matches Simon's professional aesthetic
- [ ] Not too "marketing-y" or salesy
- [ ] Colors aren't garish

✅ **Legally Safe**
- [ ] Images sourced from legitimate sources
- [ ] No watermarked stock photos
- [ ] Fair use for logos (discussing the company)
- [ ] Attribution where needed

✅ **Performance Optimized**
- [ ] Image/video size <5MB/<200MB
- [ ] Correct dimensions (1200x628 or 1200x1200)
- [ ] Video has subtitles (if applicable)
- [ ] First 2 seconds of video grabs attention

✅ **Enhances Hook**
- [ ] Visual reinforces the message (not random)
- [ ] Shows what text describes
- [ ] Creates additional curiosity
- [ ] Stops the scroll

## Advanced: AI Image Search Prompts

When using AI to help find images, use structured prompts:

**For web searches:**
```
Find me a professional headshot of [Person Name] from:
1. Their LinkedIn profile
2. [Company] press kit
3. Recent conference appearances in [Year]

Requirements: High resolution, professional, recent
```

**For logo searches:**
```
Find the official logo for [Company] in:
1. SVG format (preferred)
2. PNG with transparent background
3. Minimum 500px width

Sources: Press kit, Clearbit API, or Crunchbase
```

**For product screenshots:**
```
Find screenshots of [Product Name] showing:
1. [Specific feature]
2. From official sources (company blog, product page)
3. High quality, recent version

Alternative: Provide URL to product, I'll screenshot
```
